# Update context

## Purpose

Keep `CONTEXT.md` useful as the user's goals, circumstances, relationships,
environment, and priorities change. This job may run manually or on a
user-approved schedule.

## Workflow

1. Read `CONTEXT-SPEC.md` and the current `CONTEXT.md`. If the personal
   artifact is absent, stop and recommend the bootstrap job instead.
2. Review only new or newly relevant evidence when possible.
3. Identify material changes, stale claims, contradictions, resolved
   uncertainty, and context that no longer earns its cost.
4. Distinguish temporary state from a durable change and observed behavior
   from desired behavior.
5. Propose the smallest useful additions, revisions, or removals.
6. Ask the user to review consequential changes to goals, relationships,
   authority, priorities, or sensitive context.
7. Apply approved changes and re-evaluate the artifact against
   `CONTEXT-SPEC.md`.
8. Report what changed, why, and what remains uncertain.

A valid update may make no change. Do not preserve obsolete context merely
because it was once true, and do not silently promote transient activity into
a durable goal.
