# Learning specification

## Status

This is an initial cross-cutting contract. Concrete promotion and evaluation
mechanisms remain to be battle-tested.

Galaga should learn from observed outcomes and explicit feedback. It must
distinguish observations, interpretations, endorsed guidance, temporary
context, durable preferences, project conventions, and aspirational goals.

Evidence may be collected quietly, but consequential adaptations and
authoritative samples require appropriate user review. Changes should be
small, explainable, reversible, and evaluated by whether they improve future
decisions or actions. A learning run may conclude that no update is justified.
