# Bootstrap tasks

The task workflow is provisional. Read and follow:

1. `tasks/TASKS-BOOTSTRAP.md`
2. `tasks/TASKS-SPEC.md`
3. `utilities/cache/CACHE-SPEC.md`

Create or update the user-owned `tasks/TASKS.md`. Do not create or
assign work in an external system, or activate a schedule, without the user's
authority.
